**# AI Student Performance Analyzer**



**## Task**

**Task 11 - Create an AI/ML Application**



**## Project Overview**

**The AI Student Performance Analyzer is an interactive web application that demonstrates how machine learning can be used to explore student performance.**



**Users can enter marks, daily study hours, attendance percentage, and completed assignments. The application uses a trained Logistic Regression model to produce an illustrative Pass/Fail prediction.**



**## Technologies Used**

**- Python**

**- Pandas**

**- Scikit-learn**

**- Streamlit**

**- Matplotlib**



**## Features**

**- Interactive student input form**

**- Machine-learning-based prediction**

**- Student performance visualization**

**- General study suggestions**

**- Browser-based user interface**

**## Installation**



**Install the dependencies:**



&#x20;   **py -m pip install -r requirements.txt**



**## Train the Model**



&#x20;   **py train\_model.py**



**The trained model is saved in the models directory.**



**## Run the Application**



&#x20;   **py -m streamlit run app.py**



**## Limitations**

**This project uses a small illustrative dataset for educational purposes. Predictions are not guaranteed to be accurate and should not be used for actual academic decisions.**
